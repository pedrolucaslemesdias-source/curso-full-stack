| Comando       | Finalidade                                 |
| ------------- | ------------------------------------------ |
| `git init`    | Cria um repositório Git                    |
| `git status`  | Mostra o estado do projeto                 |
| `git add`     | Adiciona arquivos para o próximo commit    |
| `git add .`   | Adiciona todos os arquivos                 |
| `git commit`  | Cria uma versão do projeto                 |
| `git log`     | Mostra o histórico                         |
| `git branch`  | Mostra/cria branches                       |
| `git switch`  | Troca de branch                            |
| `git merge`   | Junta branches                             |
| `git clone`   | Baixa um projeto                           |
| `git remote`  | Gerencia o repositório remoto              |
| `git push`    | Envia alterações para o GitHub             |
| `git pull`    | Baixa alterações do GitHub                 |
| `git fetch`   | Consulta alterações remotas sem aplicá-las |
| `git diff`    | Mostra diferenças no código                |
| `git restore` | Desfaz alterações                          |
| `git rm`      | Remove arquivo do Git                      |
| `git mv`      | Move/renomeia arquivo                      |
| `git tag`     | Cria marcações de versões                  |
| `git reset`   | Desfaz commits/alterações                  |
| `git revert`  | Cria um commit que desfaz outro            |
