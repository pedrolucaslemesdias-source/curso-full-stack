# full-stak inrodução ao git 

# controle de versão.

# comandos git

# git init: inicia repositorio git

# git status: verifica quantos arquivos estão no stage are.

# git add . (ou arquivo): adiciona todos os arquivos manitoramento do git (mesmo se foi modificado)

# git rm --cached (tira o arquivo do stage are)

# git restore: volta atras na ultima alteração

# git commit -m "salva o ponto da versão"
 
# git log : navega entre os commits. 

# navegando pelos commits: utilizado git log junto com id no commit conseguimos voltar atrar do projeto antes de ser alterado.

# git checkout junto com id do commit mostra um commit anterior:("Passado")

# git checkout master(commit futuro)

# para recuperar um arquivo que foi apagado podemos usar ex: git chechout (id do commt) -- nome do arquivo e sua extensão.
